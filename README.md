# 🌍 TravelGram — Perfil de Viagens

Projeto de treinamento desenvolvido durante meus estudos na faculdade de tecnologia Rocketseat, com o objetivo de praticar os fundamentos de desenvolvimento web utilizando HTML e CSS.

O TravelGram é uma página estática que apresenta um perfil de viagens, reunindo informações de uma viajante fictícia e uma galeria de fotos dos destinos visitados.

## 📸 Sobre o projeto

A interface conta com:

- Menu de navegação com logotipo e links.
- Perfil com foto, nome e biografia.
- Informações sobre localização, países visitados e quantidade de fotos.
- Galeria com 12 fotografias de viagens.
- Rodapé com informações da página.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts — Poppins

## 📚 Aprendizados

Durante o desenvolvimento, pratiquei:

- Estruturação de páginas com HTML.
- Estilização e organização de arquivos CSS.
- Uso de variáveis CSS para padronizar cores e tipografia.
- Posicionamento de elementos, alinhamento e espaçamento.
- Utilização de imagens e ícones na interface.

## 💻 Como visualizar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

Também é possível visualizar o projeto pelo VS Code utilizando a extensão Live Server.
